# RQ Kitchen — تطبيق الحضور والانصراف

تطبيق ويب يُثبَّت على الجوال (PWA)، على نفس مشروع Supabase لكنه مستقل تماماً:
- كل جداوله ودواله تبدأ بـ `att_` فقط.
- له نظام دخول خاص به (إيميل + رقم سري)، ولا يضيف أي حساب في Authentication.
- لا يلمس أي جدول أو دالة لتطبيق المصاريف أو الجرد.

قاعدة البيانات جاهزة ومُشغَّلة بالفعل. ملف `supabase/schema.sql` نسخة احتياطية فقط.

## 1) الإعداد
ملف `config.js` جاهز بالرابط والمفتاح، لا يحتاج أي تعديل.

## 2) GitHub و Vercel
1. أنشئ مستودعاً جديداً `rq-kitchen-attendance` وارفع كل الملفات كما هي.
2. Vercel ← Add New ← Project ← اختر المستودع ← Framework: Other ← Deploy.
3. Vercel ← Settings ← Domains ← أضف `attendance.rqkitchen.app`.
4. Namecheap ← Advanced DNS ← سجل CNAME: Host `attendance`، والقيمة التي يعرضها Vercel.

## 3) التشغيل
1. **أول حساب يُسجَّل في التطبيق يصبح المدير تلقائياً.** سجّل حسابك أنت أولاً قبل إرسال الرابط لأي أحد.
2. في كل فرع: الإعدادات ← «استخدم موقعي الآن» ← حفظ.
3. حدّد مواعيد كل فرع من زر «موعد الدوام» في قسم «اليوم».
4. أرسل الرابط للموظفين. كل موظف يسجّل حسابه، ثم تعتمده من الإعدادات وتضيف راتبه.

## نسيان الرقم السري
المدير يعيّن رقماً جديداً من الإعدادات ← «رقم سري جديد»، والموظف يغيّره بعدها من «تقاريري».

## التثبيت على الجوال
- آيفون: Safari ← زر المشاركة ← «إضافة إلى الشاشة الرئيسية».
- أندرويد: Chrome ← «تثبيت».
